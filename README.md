## Description
Hello this is the game for the haven gamejam/hackclub <br>
the theme is: bounce back, here we implemented it with <br>
a boomerang (because boomerang always like returns=bounces back) <br>

## How to run
Install a functional java runtime (Ideally openjdk-21-jre) and <br>
then just launch it with it (on windows you can just open it as an app) <br> on linux you might just do "java -jar boomerang-thrower.jar"

## how to play
you just click where you want the boomerang to go (preferably to the enemy)
